## 三条主流路线，先分清楚

第一条是专线。IPLC（International Private Leased Circuit，国际专线）和 IEPL（International Ethernet Private Line，国际以太网专线）都是点对点独享带宽：你买 10M 就是全程 10M，不跟别人共享，晚高峰不拥堵，延迟和丢包表现最接近“办公室里拉了根内网线”。代价是按带宽包月计费，用不满也照付。

第二条是 SD-WAN。流量被调度到服务商的骨干节点上，靠智能路由动态选最优路径。云杰通信、IPdodo、51IDC 这类服务商主推的都是它：支持按需扩带宽、按应用分流（QoS 优先级），云杰通信宣称覆盖全球 160+ 节点、综合成本比传统专线低 30%–50%（服务商口径，实际以询价为准）。要注意多数 SD-WAN 的骨干是共享的，对带宽竞争敏感的业务得确认保障机制。

第三条是云厂商的全球组网。以阿里云为例，云企业网（CEN）负责跨地域互联，智能接入网关（SAG）让总部和分支通过“专线+互联网”双链路就近接入 POP 点，分钟级部署，端到端加密。如果你的电商系统、数据库本身就跑在云上，这条路最顺。

还有一条路不推荐但得说清楚：机场和来路不明的通道。今年 3 月 V2EX 上那个“小公司做跨境网络连接”的讨论里，几十条回复几乎一边倒地提醒——正经公司至少要一条合规线路保底。机场除了随时失效、没法入账，更麻烦的是连带风险：有用户直言，万一员工拿着公司的非合规通道出了事，“一供出来就说是公司提供的”，公司一样跑不掉。做跨境收款、有境外收入的公司，没必要在这上面省。

## 按业务场景选：四种常见情况

选方案的关键变量是延迟敏感度、出口 IP 要求和预算，对着下面四种情况找自己的位置就行。

1. **纯办公**：员工访问海外 SaaS、开视频会议。小带宽 SD-WAN 或运营商方案，按 300 元/Mbps/月算，5M 每月 1500 元左右。
2. **多店铺运营**：防关联的硬指标是出口 IP 固定。IPdodo 给企业组网配企业级静态 IP，云杰通信支持多国家出口 IP，都是冲着这个需求去的；独享专线在 IP 可控性上更彻底。
3. **直播和实时通信**：丢包和抖动直接掉观看。IPdodo 公开的影视出海客户案例里，客户起步阶段换了好几家供应商都出现大批量封号和卡顿，换到企业组网后才明显好转。这类业务优先独享专线，预算紧再看带 QoS 保障的 SD-WAN。
4. **合规和入账有硬要求**：至少一条有跨境资质的正规线路保底。论坛里被反复推荐的做法是“两条腿”——一条运营商背书的正规小带宽线路应付合规，大流量需求另想办法。但也有人点出软肋：合规线路和非合规通道并行时，员工的违规使用可能把公司拖下水，管理上得管得住才行。

## 跨境网络解决方案常见问题

**专线为什么查不到公开价格？**
因为按带宽、落地国家和计费周期定制，每单都不一样。常规做法是向多家服务商询价、横向对比，条件允许的话先测试再签——论坛里做过专线采购的人给的共识也是“先试用，再谈价格”。

**SD-WAN 和专线到底怎么选？**
对延迟最敏感的场景选专线，独享带宽的稳定性上限更高；多数办公场景 SD-WAN 够用，而且扩带宽、按需付费更灵活。

**公司业务用机场行不行？**
技术上能用，公司主体上不该用。没法开票入账只是小事，真正的问题是合规连带风险和随时可能断掉的业务连续性——商务场景断十几分钟就可能产生损失，这不是家用网络“等等就好”的事。

**小公司没有跨境资质，能申请专线吗？**
可以找有相应资质的服务商采购线路。也有地区性的通道：讨论里有广州用户提到，资质齐全的外贸公司可以直接去电信营业厅申请 10M 左右的外贸专线。各地门槛不同，以当地运营商答复为准。
